# rag-multiagente-nexo

Assistente interno com RAG para a **Nexo Seguros** (empresa fictícia), construído por **5 agentes de IA em paralelo**
(Claude Code) e monitorado no [Habblaud](https://habblaud.com).

> Este README será reescrito pelo agente Tech Lead ao fim do projeto.
> Para rodar, veja **[COMO-RODAR.md](COMO-RODAR.md)**.

## Estrutura
```
CLAUDE.md              contratos e regras da equipe (lido por todos os agentes)
docs/briefing-empresa.md  fatos da empresa fictícia (fonte da verdade)
agentes/               prompt de cada um dos 5 agentes
equipe/QUADRO.md       canal de comunicação entre os agentes
iniciar-equipe.ps1     abre os 5 agentes no Windows Terminal
iniciar-agente.sh      abre um agente (WSL/Linux)
COMO-RODAR.md          passo a passo + roteiro do vídeo
POST-LINKEDIN.md       rascunho do post
```
